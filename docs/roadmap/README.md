# UB OS-RUS Roadmap

## 0 Foundation
Repository, monorepo, architecture contracts and security rules.

## 1 Core
Organizations, workspaces, memberships, roles, permissions, branches and audit.

## 2 Universal Business Engine
Entities, fields, records, statuses, relations and views.

## 3 Workflow Engine
Triggers, conditions, actions, schedules and workflow runs.

## 4 Business Modules
CRM, sales, services, products, inventory, finance, projects, employees, documents and support.

## 5 AI OS
Assistant, agents, natural-language commands, analytics and automation generation.

## 6 Industry Packages
Configurable packages for many industries without changing the core.

## 7 Integrations and Production
Payments, messaging, accounting, APIs, webhooks, observability and security testing.
